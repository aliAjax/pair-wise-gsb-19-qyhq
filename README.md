# hxwl-05 鱼缸水质台账

多鱼缸水质检测台账：录入、概览、异常提醒与历史明细，数据保存在浏览器本地。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- 鱼缸管理：新增、改名、点击切换，概览/异常提醒/明细随选中鱼缸联动
- 检测录入：pH、氨氮、亚硝酸盐、硝酸盐、硬度、温度、换水量，支持自定义检测时间
- 本地持久化：所有数据写入 localStorage，刷新或重新打开浏览器不丢失
- 最新状态：只取检测时间最晚的一条，补录较早的历史数据不会覆盖最新状态
- 重复检测：同一天多次检测全部保留，明细按日期分组、时间倒序展示
- 异常提醒：氨氮 > 0.5 ppm 或亚硝酸盐 > 0.2 ppm 时概览卡片、提醒条和明细记录标红，并列出具体超标指标与阈值

## 数据说明

- 存储键：`aquarium-ledger-v1`（localStorage）
- 每条记录包含检测时间（testedAt）与录入时间（createdAt），排序与"最新"判定均以检测时间为准
